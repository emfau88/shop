# AUFSCHLAG Signature · Bildbedarf

Die erste Signature-Fassung verwendet bewusst die vorhandenen, responsiven AUFSCHLAG-Fotografien aus dem übergeordneten Ordner. Herkunft, Prompts und Originaldateien sind in `design/generated/sportverein/manifest.json` dokumentiert. Es werden keine Dateien dupliziert und keine externen Bilder nachgeladen.

Für eine spätere finale Fotoproduktion würden diese fünf Motive einen sichtbaren Qualitätsgewinn bringen:

1. Tennisball exakt auf einer weißen Clay-Linie, mit Sandstaub im Gegenlicht.
2. Makroaufnahme von Schlägergriff und Hand unmittelbar vor dem Aufschlag.
3. Shuttlecock und Besaitung im Treffmoment vor ruhigem Hallenhintergrund.
4. Schuhabdruck und kurze Rutschspur auf rotem Sand als stilles Detailmotiv.
5. Ungestellter Moment nach einem Abendtraining am langen Tisch der Clubterrasse.

Benötigte Produktionseigenschaften: natürliche Editorial-Sportfotografie, keine sichtbaren Markenlogos, großzügige Cropping-Reserve für 16:9 und 4:5, abgestimmtes Blau/Off-White mit Lime nur als realem Akzent sowie schriftlich geklärte Webnutzung.
